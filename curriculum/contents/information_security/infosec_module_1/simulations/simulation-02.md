# 🧠 Simulation — Threat, Vulnerability, or Risk?

## Instructions

You will be shown several situations.

For each one, decide whether it represents:

- A **Threat**
- A **Vulnerability**
- A **Risk**

---

## Scenarios

1. A hacker group actively targeting financial institutions  
2. A web application running outdated software  
3. A public-facing server with weak authentication that could be exploited  

---

## Reflection

After classifying each scenario, ask yourself:

- What would need to change for this to become a real incident?
- Which of these can you control?
- Which of these only exist when combined?

---

## Key Insight

> A vulnerability without a threat is harmless.  
> A threat without a vulnerability is ineffective.  
> **Risk exists only when both meet.**
